# Backend trước khi tách dịch vụ

`backbook-server` là bản backend trước khi chuyển sang microservices, giữ để tham khảo lịch sử và lấy dữ liệu/ảnh khi chạy script migration. Không phải backend đang phục vụ website.

Các thay đổi mới cần thực hiện trong `services/`, không sửa bản legacy rồi kỳ vọng website tự cập nhật. Xem README ở thư mục gốc để khởi động hệ thống hiện tại.
