# PTITSocial Web

Giao diện React cho bảng tin, bạn bè, tin nhắn và khu vực học tập.

Xem [hướng dẫn chạy toàn bộ project](../../README.md). Từ thư mục này, có thể cài dependencies, chạy test và kiểm tra bản build.

```powershell
npm.cmd ci
npm.cmd test -- --watchAll=false --runInBand
npm.cmd run build
```
