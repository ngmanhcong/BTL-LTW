# Source React

- `pages`: các màn hình chính.
- `features/auth`: đăng nhập, đăng ký, quên mật khẩu, xác minh email.
- `features/posts`: bài viết, ảnh, bình luận và lượt thích.
- `features/profiles`: chỉnh sửa hồ sơ và ảnh đại diện/ảnh bìa.
- `features/connections`: kết bạn, tìm người dùng, khối cộng đồng.
- `features/messaging`: chat, theme hội thoại và hook gửi/nhận tin.
- `features/navigation`: header, menu và sidebar.
- `features/notifications`: hook thao tác thông báo.
- `shared`: UI, icon, thư viện và hook dùng chung.
- `app`: Redux store/state.
- `routes`: ánh xạ URL và kiểm tra phiên đăng nhập.

Import từ gốc `src` được cấu hình trong `jsconfig.json`. Font, giao diện và API Gateway vẫn giữ như trước khi tổ chức lại source.
